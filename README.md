# 🚀 Models Dashboard (fully vibe coded)

A sleek, modern, zero-paywall clone and live aggregator inspired by [breaf.in](https://breaf.in). This dashboard lets you track **free-to-use LLMs** across various providers in real time, inspect comprehensive token economics/stats, and view model benchmark scores—all with zero subscription locks or paywalls.

![Dashboard Preview](https://img.shields.io/badge/Status-Live%20%26%20Active-success)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## ✨ Features

* **🆓 Free Right Now Tracker**: Automatically filters and displays models that are completely free to call ($0.00 / 1M tokens) across top providers (OpenRouter, NVIDIA NIM, Cohere, Google Gemini, and more).
* **📊 LLM Stats & Token Economics**: Full data tables listing context window lengths, prompt costs, and completion costs per million tokens.
* **🏆 Benchmarks & Intelligence Index**: Clean progress-bar rankings evaluating top models based on reasoning and intelligence scores.
* **⚡ Live API Synchronization**: Fetches live model inventories dynamically on load with offline fallback support.
* **🛠️ One-Click API Setup**: Instant copyable cURL endpoints and OpenAI-compatible configuration snippets for tools like Claude Code, Codex, and custom scripts.
* **🎨 Dark Aesthetic**: Matches the clean, warm dark-brown theme (`#120D0B`) for a distraction-free developer experience.

---

## 🛠️ Tech Stack

* **Frontend**: Pure HTML5, Tailwind CSS (via CDN)
* **Icons**: FontAwesome 6.4.0
* **Data Source**: OpenRouter Public Models API & Local Fallback Catalog
